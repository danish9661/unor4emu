Proof inventory

Snapshot core core/ra4m1-periph-wasm: 117 tests (37 legacy CPU/system + 80 R4 proofs). Small core core/ra4m1-core: 80 R4 proofs (79 mirror + EK zero-boot). Always run single-threaded — shared globals (SYS, INSTRUCTION_COUNT, UART buffer) flake in parallel.

cargo test --manifest-path core/ra4m1-periph-wasm/Cargo.toml --lib -- --test-threads=1
cargo test --manifest-path core/ra4m1-core/Cargo.toml --lib -- --test-threads=1
cargo build --manifest-path Cargo.toml

Known quirks

  • Run tests with --test-threads=1: shared SYS, instruction count, and UART buffer flake in parallel.
  • rx_inject raises BRDY like hardware; CCPL is a strobe; CFIFO OUT drains are single bytes.
  • RIIC: ST auto-sets MST/TRS; TDRE+TXI fire on START; enables fire latched flags; the first RXI read is a dummy; restart-write has no completion event.
  • Virtual time runs on instruction count; ADC converts instantly; CAN loopback needs self-test mode; I2C slave jig lives at 0x50; SPI loopback is a test jig (open bus reads 0xFF); DTC transfers complete in the CPU run loop while staged.
  • GPT compares are crossing-detected; unprogrammed all-ones compares are bounded by the period so they never false-fire on wrap.
  • PORT and PFS are separate instances keyed by an explicit flag; PWM pins follow GPT latches only when PFS PSEL selects a GPT function.
  • DTC repeat/block length reads CRAL (R_DTC doubles length into CRAL+CRAH, so a programmed 24 reads back 0x1818).
  • Sub-word reads return unmasked packs in JS — mask with % 256. Data registers (ICDRR/SPDR) are never polled; a read would eat the firmware's byte.
  • D13 is P111 (PORT1 bit 11), not bit 13.

Build and test

Top workspace builds Minima only; WiFi is parked and excluded. demo/pkg/ + demo/fw/ are generated (git-ignored); only index.html, docs.html, about.html, app.js, styles.css, build.sh are tracked.

./demo/build.sh
python3 -m http.server -d demo 8901
cargo build --manifest-path Cargo.toml

Vendored firmware (core/blinky/r4*.bin) is built with arduino-cli 1.6.0 and committed; the Pages workflow rebuilds pkg+fw and publishes demo/.
