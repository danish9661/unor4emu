Real ArduinoCore Blink.ino (FSP + millis from AGT0 1 ms IRQs) running on the core. The LED and pin grid follow the actual PORT registers.

Real Serial sketch over emulated USBFS: the page plays virtual host (attach → reset → descriptors → line coding → DTR), then Serial.println("hello") lands here.

    Echo sketch: bytes you send travel host → bulk-OUT → Serial.read → Serial.write → bulk-IN → back here. Pipes are discovered from PIPECFG like a real host.

    Wire master (IIC1) vs a bare-metal slave (IIC0 @ 0x42): the master writes 0xBE, the slave replies 0xEF. Flags below are live MMIO — data registers are never touched (reading one would eat the firmware's byte).

      SPI0 master vs SPI1 slave on one chip: the slave stages 0x5A, the master shifts 0xA5 — both bytes cross in one exchange. Status below is live MMIO.

        Virtual SD card in SPI mode: Arduino SPI runs the real init (CMD0/CMD8/ACMD41), reads block 0 (MBR signature), writes a pattern to block 1 and reads it back. The dump below is read straight off the virtual card afterwards.

          CAN0 self-test loopback into the RX FIFO: mailbox 0 transmits (SID 0x123), the frame lands in the FIFO and is read back through the MB24 port. FIFO reads below never pop — only the firmware's RFPCR write does.

            Arduino EEPROM library on the dataflash window: two bytes go through the real FSP erase/program path and are read back from 0x40100000 itself. The bytes below are live dataflash reads.

              GPT0 PWM at 25% duty on D6 (P106): the pin follows the timer's compare output live — the grid cell blinks and the measured duty is shown. An LED cannot show duty, so the numbers are the verdict.

                Real ArduinoCore analogWrite(6, 64) on GPT0 (490 Hz, 8-bit): the sketch hits R_GPT_DutyCycleSet, which programs the GTCCRD buffer with GTBER transfer — the live GTPR/GTCCRB/GTIOR below are the verdict (bare-metal duty waveform is measured in the PWM tab).

                  Real ArduinoCore tone(LED_BUILTIN, 440): an FspTimer in PERIODIC mode toggles D13 from its overflow IRQ. The LED and grid cell follow live — the toggle is the verdict.

                    Real ArduinoCore SoftwareSerial loopback at 9600 baud: TX on D3 (P104) is wired on-page to RX on D2 (P105, IRQ0); GPT4/GPT5 timers plus DMAC0/DMAC1 move one PCNTR sample per half-bit. The sketch sends 0xA5 and prints got=A5 on Serial1 — the terminal below shows it.

                      Real ArduinoCore RTC.setAlarmCallback (seconds-match at :00): the sketch sets 11:59:55 and the alarm callback lights D13 when the match crosses. The register verdict is edge-latched — one IRQ per :00 crossing, not a level re-fire.

                        CAN bus-off recovery on the real Arduino_CAN stack: the sketch transmits in a loop and checks isError(). The page injects a TX error storm (TEC saturates, BOEF latches), recovers via halt→operation (counters reset, TX completes again). The LED is the verdict.

                                  12×8 LED matrix, charlieplexed on real GPIO (the same 11 pins as hardware): the sketch multiplexes a smiley faster than the eye. The grid below accumulates lit LEDs with persistence — like vision does. No panel on Minima; the pattern is the verdict.

                                    Bare-metal EK-RA4M1 target (R7FA4M1AB3CFP, same RA4M1 silicon as Minima in a 100-pin LQFP): no Arduino bootloader — flash boots at 0x00000000 — and the user LED1 is on P106 (EK manual §5.4.4), not Minima's P111/D13. This runs the zero-boot P106 proof live; flip the Board selector above to EK-RA4M1 to watch LED1 follow PORT1.6 on the grid.
